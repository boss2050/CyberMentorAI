# CyberMentorAI

Built by a student, designed to help others learn cybersecurity through AI.

CyberMentor AI is an interactive cybersecurity learning platform that helps beginners explore cybersecurity concepts through AI-powered conversations, quizzes, mini challenges, and progress tracking.

## 🚀 Features

* 💬 Interactive cybersecurity chat assistant
* 📝 Dynamic quizzes and mini challenges
* 📈 XP and progress tracking system
* 🏅 Achievement-based learning
* 🔒 Topics like SQL Injection, Phishing, HTTPS, VPNs, Firewalls, and more
* 📱 Responsive modern UI
* ⚡ Lightweight frontend-based architecture

## 🎯 Purpose

Cybersecurity can feel overwhelming for beginners because of complicated terminology and dense learning resources. CyberMentor AI was created to make cybersecurity education more approachable, engaging, and interactive for students and new learners.
